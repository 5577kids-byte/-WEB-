# Gemini用動画プロンプト

このフォルダの4ファイルは、同じキャラクターや世界観を保ったWebサイト用動画を作るための追加プロンプトです。

完成済みの動画ファイルは、この公開テンプレートに含まれていません。付属の静止画を参考にしながら、自分のサイト用の動画を生成してください。

## 使い方

1. 利用権のあるベース画像を用意します。
2. Geminiの画像・動画生成画面へベース画像を読み込ませます。
3. 作りたい場面に対応するMarkdownの本文を追加プロンプトとして貼り付けます。
4. 生成結果を確認し、文字・ロゴ・不要な記号が入っていないものを選びます。
5. MP4として `source-videos/` へ保存します。
6. `bash scripts/compress-videos.sh` を実行してWeb用に圧縮します。
7. Claude Codeへ「生成した動画を各ページの静止画と差し替えて、表示検査まで進めて」と伝えます。

## 対応表

| プロンプト | 役割 | 出力ファイル名 |
|---|---|---|
| `01-hero-intro.md` | サイト導入・ヒーロー映像 | `01-hero-intro.mp4` |
| `02-ai-training.md` | 知識・学習・担当者ページ | `02-ai-training.mp4` |
| `03-automation-flow.md` | 業務自動化・サービスページ | `03-automation-flow.mp4` |
| `04-development.md` | 開発・ポートフォリオページ | `04-development.mp4` |

4本とも、ベース画像を主な視覚参照として先に読み込ませる前提です。別のキャラクターへ変える場合は、プロンプト内の色、装甲、ヘルメットなどの指定も合わせて変更してください。

生成サービスの利用条件と、参照画像・生成動画の利用権は公開前に確認してください。
